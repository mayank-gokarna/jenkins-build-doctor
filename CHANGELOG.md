# Changelog

## 0.1.0

- Initial release: Jenkins Explorer tree (folders, multibranch, organization folders), search/filter, build selection.
- Rule-based failure diagnosis with ~90 rules, confirmed/hypothesis separation, evidence with line numbers and stages, remediation steps.
- Diagnosis webview, console log documents, Markdown export.
- Optional AI analysis (VS Code LM API, Amazon Bedrock Converse, OpenAI-compatible) with explicit consent and redaction.
- SecretStorage credentials, secret redaction, structured logging, unit and integration tests.
